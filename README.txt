To use your own PNG/JPG:
1. Put your app icon image in app/src/main/res/drawable/app_icon.png
2. Put your splash image in app/src/main/res/drawable/splash.png
3. If using splash.png, change windowSplashScreenAnimatedIcon in themes.xml
   to @drawable/splash (Android splash uses a centered icon; it does not stretch
   a full-screen image).
4. Commit and run GitHub Actions.

The app has no drawer, no browser toolbar, JavaScript enabled, fullscreen,
and Android Back follows WebView history.
